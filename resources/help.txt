tnotify - tmux notification manager

SYNOPSIS
  tnotify [-h | -v | --skill | --config | --defaults]
  tnotify notify <body> [--head <heading>] [--author <name>]
                        [--interactive [<option>...] [--custom] [--multiple]]
  tnotify show [--all | --last]
  tnotify clear [--all | --head <n> | --tail <n> | <number>...]
                [--author <name>]

OPTIONS
  -h, --help                 Print this help documentation and exit
  -v, --version              Print version information and exit
  --skill                    Display or configure skill settings
  --config                   Print the config path, creating it from the
                             defaults when there is none
  --defaults                 Back up the current config and write the defaults

COMMANDS
  notify <body>              Send a notification, <body> being its message
    --head <heading>         Heading shown above the message
    --author <name>          Who sent it; defaults to $TNOTIFY_AUTHOR, else the
                             calling script or program
    --interactive [<option>...]
                             Offer options to pick from; the chosen one is
                             printed in the original terminal
    --custom                 Add a text box to type an answer in; requires
                             --interactive
    --multiple               Select several options with space; requires
                             --interactive

  show                       Display the notification history
    --all                    List every waiting notification in a side panel,
                             each in a numbered box of its own. Move between
                             them with the arrow keys or j/k, go straight to
                             one with :<number> and [enter], throw one away
                             with [del], and open the one in focus with
                             [enter] to pick from its options; [esc] closes it
                             again and [q] closes the panel. An answer given
                             here is typed into the pane the notification was
                             sent from, the same way "show --last" delivers one
    --last                   Raise the most recently ignored notification
                             again, as it first arrived, to answer now. The
                             answer is typed into the pane it was sent from,
                             without being run; ignoring it again leaves it
                             waiting

  clear [<number>...]        Throw notifications away without answering them,
                             each <number> being one the side panel draws on a
                             box, or a range of them (e.g. 1 2 4-5). Commas
                             between the numbers are allowed
    --all                    Clear every waiting notification
    --head <n>               Clear the <n> that have been waiting longest
    --tail <n>               Clear the <n> that arrived most recently
    --author <name>          Clear only what this author sent. On its own it
                             clears all of them; with --all, --head or --tail
                             it narrows those to that author. It cannot be
                             given alongside numbers, which always count from
                             the whole list

NOTES
  An ignored notification is kept, so that "show --last" can raise it again
  and answer it later; one cleared with [del] is not. The pane a notification
  was sent from is retitled "tnotify:<n>" while it is waiting, and put back
  once nothing is. A notification whose pane has since closed is orphaned: it
  can still be read and answered, but its answer is printed rather than sent.

ENVIRONMENT
  TNOTIFY_AUTHOR             Name recorded as the sender when --author is
                             not given. The caller that actually ran tnotify
                             is recorded alongside it either way
  XDG_STATE_HOME             Where ignored notifications are kept; defaults
                             to ~/.local/state

FILES
  ~/.config/tnotify/config.toml
  ~/.local/state/tnotify/notifications.json
